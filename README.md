# mk_niwar_ind_web

A professional multi-page static website for Mukesh Niwar Industries with a polished B2B presentation.

## Files

- `index.html` — home page with brand overview, trust messaging, product preview, and contact call-to-action.
- `about.html` — company history, manufacturing strength, and pan-India supply positioning.
- `products.html` — product catalog for cotton niwar, ropes, tapes, and yarn.
- `quality.html` — quality assurance and testing details for durable industrial products.
- `contact.html` — contact details, WhatsApp quick-link, and Google Maps location.
- `styles.css` — responsive brand styling using navy, white, and red accent colors.
- `script.js` — mobile navigation toggle for small screens.

## Local preview

Open `index.html` or any page in a browser to preview the website.
